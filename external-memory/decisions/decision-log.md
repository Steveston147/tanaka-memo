# Decision Log

Keep this file as a compact chronological index. Detailed decisions can be stored as separate files when needed.

| Date | Area | Decision | Status | Detail |
|---|---|---|---|---|
| YYYY-MM-DD | example | Example decision | DECIDED | `YYYY-MM-DD-example.md` |

## Rules

- One row per meaningful decision.
- Record rationale in the detail file when the reason may matter later.
- If a decision changes, do not erase history. Mark the old decision `SUPERSEDED` and add the new decision.
- Avoid transient tasks and ordinary to-do items; this is for context worth remembering.
