## Retrieval priority

1. Search this index for the topic.
2. Search the relevant folder using specific project or decision keywords.
3. Fetch only the files needed for the current question.
4. Treat archived material as historical context, not current truth.

## Status labels

Use these labels inside active files:

- `CURRENT` — presently valid
- `PROVISIONAL` — working assumption, not final
- `DECIDED` — explicit decision
- `SUPERSEDED` — replaced by newer information
- `ARCHIVED` — retained only for history

## Date rule

Use ISO dates: `YYYY-MM-DD`.

## Source rule

When useful, note where the information came from, such as a meeting, email, official document, or user decision. Do not copy sensitive source material into this repository.
